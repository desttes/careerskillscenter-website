1. **Short answer:** yes. IT support is learned and practiced on computers, and the industry hires on certifications plus demonstrated skill.
2. **The certification ladder:** CompTIA Tech+ (entry level; replaced ITF+) → CompTIA A+ (the standard help-desk credential) → Network+/Security+. Match CSC's program to where it sits `[VERIFY against it-support-specialist.html and comptia.org]`.
3. **What employers look for:** troubleshooting, ticketing systems, customer service, basic networking, Windows/Microsoft 365, and a home-lab or project portfolio.
4. **How to get hands-on practice online:** virtual labs, home lab with an old PC, volunteer IT help.
5. **Massachusetts angle:** Boston-area hospitals, universities and biotech companies all run help desks. Per Scholas and JVS run free programs, which shows demand. Don't name competitors in the post; just say "strong demand in MA."
