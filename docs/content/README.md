## Shared facts (use across posts)
| Fact | Source |
|---|---|
| Massachusetts has **16 local workforce areas**, each with a MassHire Workforce Board, and **about 29 MassHire Career Centers** where residents apply for training funds. | Project research doc 02; verify count at mass.gov/masshire-career-centers `[VERIFY count]` |
| The **MassHire Department of Career Services (MDCS)** maintains the state's Eligible Training Provider List (ETPL). Only ETPL-listed programs can be paid with a WIOA training voucher (ITA). | mass.gov; Project doc 02 |
| Job seekers must register in **MassHire JobQuest** (jobquest.mass.gov) and have a **MyMassGov** account. | masshiredowntownboston.org; Project doc 02 |
| Typical process: contact a career center → attend a **Training Information Meeting** (some centers use a required video instead) → **TABE** reading/math assessment → eligibility documents → choose an approved program → **ITA** request/training proposal → approval. **About 6–8 weeks.** Steps vary by center. | masshirecentralcc.com/jobseekers/training-education/training-assistance/ ; masshiremncareers.com/career-development-options-cdo/ |
| Documents centers commonly ask for: proof of work authorization, proof of age, Selective Service registration (men born after Jan 1, 1960), household income for the last 6 months, family size proof, and layoff paperwork if laid off. | masshirecentralcc.com (training assistance page) |
| Example income table: MassHire Central lists 2026 "economic disadvantage" thresholds from **$15,960 to $60,124+ depending on family size**. Thresholds differ by region, so present this as an example only. | masshirecentralcc.com |
| **Funds can run out mid-year**, so apply early. | Project doc 02; career-center guidance |
| **Section 30 / Training Opportunities Program (TOP):** lets people on unemployment keep collecting benefits while in a full-time approved training program (≥20 classroom hours/week). Up to **26 extra weeks** possible. Apply to DUA **by the 20th compensable week** of the claim. It does NOT pay tuition. | mass.gov/info-details/training-opportunities-program-section-30 |
| **Senator Kenneth J. Donnelly Workforce Success Grants** (formerly the Workforce Competitiveness Trust Fund) fund training partnerships for unemployed, underemployed and incumbent workers. The money goes to organizations (not individuals), which then offer training free to participants. Recent rounds: $7.4M (Oct 2025), $5.9M (Aug 2026). | commcorp.org/program/senatordonnellygrants/ ; mass.gov press releases |
| **Workforce Training Fund – Express Program:** employer-side. Businesses get reimbursed for training current employees. Administered by Commonwealth Corporation. | commcorp.org/subprogram/wtfp-express-program-guidelines/ |
| Veterans and eligible spouses get **priority of service** in WIOA programs. | WIOA / U.S. DOL (federal rule) |
