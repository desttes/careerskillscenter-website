# Career Skills Center — website

Static site for https://careerskillscenter.com (Quincy, MA). As of Sept 2026 the
site is an honest **guide to careers and training funding in Massachusetts**
(guide mode) that routes people outward to the state; Career Skills Center plans
to offer its own training in healthcare, IT and the skilled trades later.

**Start here:** `docs/GUIDE_MODE_SPEC.md` (current plan) and `docs/BUILD_STATUS.md`
(what's been built). `docs/SITE-STRUCTURE.md` and `docs/PAGES.md` are older
reference docs that predate guide mode — use them for design tokens/components
only, not the current page list.

- `index.html` — landing page (the guide homepage)
- Inner pages generated by `tools/build-pages.py`: `career-paths.html`, the three field guides (`healthcare-careers-massachusetts.html`, `it-careers-massachusetts.html`, `skilled-trades-careers-massachusetts.html`), `qualify.html`, `student-financing.html`, `about.html`, `faq.html`, `contact.html`, `blog.html` + `blog/*`, `privacy-policy.html`, `terms-of-use.html`, plus 10 redirect stubs for retired pages
- `css/style.css`, `js/main.js` — shared styles and behaviour; `js/site-config.js` — guide/course switches + feature flags
- `.htaccess` — 301 redirects for retired pages
- `images/` — site images
- `tools/build-pages.py` — regenerates the inner pages from the shared header, footer and dialog in `index.html`

The header, footer and contact dialog live once in `index.html`. Edit them
there, then run:

```bash
python3 tools/build-pages.py
```

Open `index.html` directly in a browser, or serve the folder with any static
server (for example `python3 -m http.server 8080`).
